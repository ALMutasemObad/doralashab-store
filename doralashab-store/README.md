# متجر دار الأصحاب

حزمة WordPress/WooCommerce مخصصة لشركة دار الأصحاب للنشر والتوزيع.

## المحتويات

- `wp-content/themes/doralashab`: قالب عربي خفيف متوافق مع WooCommerce.
- `wp-content/plugins/doralashab-books`: إضافة بيانات الكتب والمؤلفين والاستيراد.
- `../data/woocommerce-products.csv`: ملف المنتجات المستخرج من الموقع القديم.

## ترتيب التثبيت

1. تثبيت WordPress وWooCommerce وتفعيل العربية.
2. رفع وتفعيل إضافة `doralashab-books`.
3. رفع وتفعيل قالب `doralashab`.
4. استيراد `woocommerce-products.csv` من المنتجات ← كل المنتجات ← استيراد.
5. مراجعة المنتجات التي بلا سعر أو وصف قبل فتح المتجر للعامة.
6. ضبط الشحن والدفع والضرائب وسياسات المتجر.

لا تعدل ملفات WordPress أو WooCommerce الأصلية. كل التخصيصات موجودة في القالب والإضافة.
